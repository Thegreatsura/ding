# Security policy

If you suspect a security vulnerability in Ding, [report it privately on GitHub](https://github.com/YusufCeng1z/ding/security/advisories/new). Keep vulnerability details out of public issues, pull requests, and discussions while the report is being reviewed.

Include the affected package and version, the browser and framework if relevant, the conditions needed to trigger the issue, and the impact you observed. Share a minimal reproduction if you can, with credentials and private data removed.

The maintainer will use the private report to coordinate investigation, fixes, and disclosure. For ordinary bugs, use the [public issue tracker](https://github.com/YusufCeng1z/ding/issues).
